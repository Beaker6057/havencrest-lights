# Havencrest Lights

Small helper pages for the Havencrest Lights viewer page (havencrestlights.remotefalcon.com).

- `suggest.html` — the "Don't see your song?" box. Remote Falcon removes scripts from viewer pages, so this box is hosted here on GitHub Pages and shown in a frame under the Show Hours card. It sends to the Google Form "Havencrest Lights Song Requests", shows a green confirmation, then clears.

If a question in that Google Form is changed or recreated, update the entry IDs in `FIELDS` inside `suggest.html`.
